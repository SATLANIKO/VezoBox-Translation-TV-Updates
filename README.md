# VezoBox Translation TV — Application Updates

Public update and download repository for the **Android TV / Google TV application**.

## Scope

- TV application APK files and release notes, when approved for publication.
- TV application versions are independent from the Windows app and the website.
- The Stremio addon and its server are separate and are not distributed here.
- Application source code, private configuration and credentials remain private.

## Downloads

No TV application installer has been published to this repository yet. Approved APK files will appear under [Releases](https://github.com/SATLANIKO/VezoBox-Translation-TV-Updates/releases).

Creating this repository does not publish a customer release or change the application version.
